# PAPILA Ophthalmology Data Analysis
Exploratory Data Analysis (EDA) of ophthalmic patient data from the PAPILA dataset using Python.

## 📌 Project Overview

This project explores ophthalmic clinical data using Python and common data science techniques.

The goal was to practice data cleaning, descriptive statistics, data visualization, and correlation analysis while working with a real-world healthcare dataset.

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## 🔍 Analysis Performed

* Data cleaning and preparation
* Handling missing values
* Identifying numerical and categorical variables
* Descriptive statistics
* Mean, median, variance and standard deviation
* Probability distributions
* Percentiles
* Data visualization
* Covariance and correlation analysis
* Correlation heatmaps

## 📊 Dataset

The project uses ophthalmic patient data from the PAPILA dataset.

The analysis focuses on variables including:

* Age
* Gender
* Diagnosis
* Refractive measurements
* Intraocular pressure (IOP)
* Pachymetry
* Axial length
* Visual field mean deviation (VF-MD)

## 📈 Key Findings

The exploratory analysis identified several relationships between variables, including correlations between age, refractive measurements, axial length and visual field mean deviation.

These findings are exploratory associations and should not be interpreted as evidence of causation or clinical conclusions.
